# PHL 0.1.0-alpha.2

这一版修掉了 alpha.1 里三个**直接影响使用**的问题。核心链路没有改动。

## 修了什么

**点「插件」会白屏。** 在还没有实例时切到「插件库」，页面会整块变白，只能重启应用。
原因是页面里有一个 Hook 写在提前返回之后，React 抛错后整棵界面被卸载。现在可以正常浏览约 3400 条插件目录，
详情页与各标签切换都正常。

**刷新会弹出一个黑色控制台窗口。** 探测 Node 版本、查找 npm、重建目录链接时，Windows 会为这些命令行程序各开一个控制台窗口。
现在它们都在后台静默运行。

**放大界面后窗口按钮被切掉。** 界面缩放到 110% / 125%，或窗口较窄时，标题栏右侧的最小化 / 最大化 / 关闭会被挤出屏幕。
现在窗口控制按钮始终完整可见（窄窗口下导航只显示图标，选中态照常）。

## 这一版包含

- 实例、版本、运行时、插件、Bundle、快照、诊断等核心链路均真实落盘并真实拉起进程。
- 应用标识换成鲸鱼尾鳍，任务栏图标按显示器缩放自行挑选尺寸。
- 仓库改为 MIT 许可证，README 与发布页重写。

## 已知情况

- 安装包未做代码签名，首次下载与运行会有 SmartScreen 提示（见下）。
- alpha 阶段：界面与数据格式仍可能变化，暂不提供自动更新。
