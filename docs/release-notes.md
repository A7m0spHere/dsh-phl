# PHL 0.1.1-alpha.1

这一版把 2026-09-29 全项目评审的 P1 与 8 项 P2 修复全部落地，并新增对官方 DeepSeek
Harness 桌面端的只读单例管理；实例页卡片网格在小窗口与高缩放下的一批排布问题一并修掉。
Windows 与 macOS 继续同版发布。

## 官方桌面端管理（新增）

- **发现与启动。** 实例页新增「官方桌面端」卡片：自动发现本机安装的官方 DeepSeek
  Harness 桌面端，展示版本与运行状态（运行中呼吸点、未运行、状态未知严格区分），
  可一键启动。PHL 只做只读协助管理——官方桌面端的安装与自更新仍由官方安装器与
  更新器拥有，每台机器至多一个，所有事实现场重探、不做状态缓存。
- **退出先礼后兵。** 先温和请求退出并给 15 秒宽限；仍存活时先弹确认，确认后才强制
  结束整棵进程树。进程判定带双重完整路径身份门，绝不从截断的快照下结论。
- Windows 与 macOS 可用；Linux 上明确报不支持。

## 可靠性与正确性

- **快照还原不再触碰会话。** 还原快照不再回滚或删除现网会话与附件：还原前先把现网
  目录移入暂存树，任何失败都发生在交换之前；UI 文案同步改为「会话与附件保留现网」。
- **密钥可以显式清除了。** 供应商卡片新增「清除密钥」按钮（带确认框）；「本机密钥」
  徽章改为如实反映本机是否存有密钥，不再靠猜测。
- **权威写入落盘更稳。** 数据根指针、迁移日志与实例清单改为「唯一临时名 + fsync +
  原子改名」，崩溃或断电不再留下半截文件。
- **健康探测不再无限等。** 运行时健康检查与版本探测加 5 秒超时并杀掉无响应子进程，
  PATH 上有卡死 shim 时不再拖住整个操作。
- **依赖安装按 semver 挑运行时。** 多个可用 Node 并存时按版本从高到低选择，
  node-22 不再输给 node-9。
- **数据根切换与迁移互斥。** 存在未完成的迁移日志时直接拒绝切换数据根，不再制造
  交错状态。
- **暂存残留清扫补全。** 试用升级与接入流程的 `.phl-trial-` / `.phl-adopt-` 暂存目录
  纳入清扫，5 棵暂存树全部回收。
- **实例编辑的端口校验。** 保存时拒绝非整数与越界端口并给出提示，不再假成功。
- **pack 清单版本字段加闸。** `dsh.version` 与 `runtime.nodeVersion` 只接受安全字符集，
  拒绝 `..` 等路径花样；commit SHA 切片加长度与字符校验，杜绝恶意输入触发 panic。
- **对话框 promise 不再泄漏。** 被顶掉的确认/输入对话框 promise 如实兑现，
  不再留下永远悬空的等待。

## 使用体验

- 实例卡片网格改由容器查询决定列数，两列阈值降到 480px：125% 缩放的窄窗口不再是
  单列长条，容器查询缺失时有回退；提示气泡不再卡在屏幕上。
- 卡片排布压缩，运行状态与端口时间并回已有行，一屏能多看几个实例。

## 说明

- **Windows**：rc.2 及更早的可自动更新版本可在「设置 → 关于」直接检查并安装本版本；
  安装包未做 Authenticode 签名，SmartScreen 提示见安装说明。
- **macOS**：仅 Apple Silicon；未签名未公证，首次打开需右键 →「打开」；本版不含
  应用内自动更新，升级需手动下载新 DMG。
- **Linux**：暂无安装包，凭据管理器在 Linux 上仍不可用（保存含密钥的 API 配置会
  明确报错）；官方桌面端管理同样明确报不支持。
- alpha 阶段数据格式与界面仍可能调整；同一数据目录不支持多个 PHL 窗口同时管理
  同一个实例。
