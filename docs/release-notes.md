# PHL 0.1.1-alpha.2

本次修复快照还原中断时可能丢失现有会话与附件的问题，并更新 Rust 安全依赖。
Windows 与 macOS Apple Silicon 继续同版发布。建议使用旧版本的用户升级。

## 快照还原的数据安全修复（#3）

- 还原前先复制现有会话与附件，复制完整后才交换目录；复制失败或取消时原目录保持完整。
- 目录交换失败时归还完整备份；中断后在列出实例或启动前恢复事务。
  遇到冲突、损坏记录或无法确认的状态会报错并保留现场，避免继续清理唯一副本。
- 创建、删除、还原快照共用事务文件锁，防止另一个 PHL 进程误清理正在还原的目录。
- 成功还原仍只回滚配置与插件，保留现有会话和附件；重复恢复也不会覆盖提交后产生的新消息。
- 回归测试使用独立临时数据，覆盖复制、目录交换、回滚、清理失败，以及 8 个检查点的真实子进程强杀与重启恢复。

还原现在需要额外空间临时复制会话和附件。若提示状态无法确认，请保留错误中列出的暂存和备份目录，
不要手动删除；该修复不代替独立备份，也不能恢复此前已被删除的数据。

## 依赖安全修复（#15）

- 更新 `webpki-roots` / `webpki-root-certs` 至 1.0.10、`rustls-webpki` 至 0.103.16，
  修复 eMudhra / emSign 证书信任链相关安全公告；同时升级 `rustls`、`quinn-proto`、`zip` 与 `ruzstd`，
  处理本轮完整锁文件审计命中的漏洞条目。
- HTTPS 与更新检查继续验证证书，没有关闭校验来规避错误。
- CI 和发行流程加入 RustSec 审计，构建使用更新后的锁文件；旧安装包不会随源码更新自动获得修复。
- ZIP 导入与导出继续校验路径和完整性，并保留旧 CP437 文件名兼容性。
  Windows 自动更新继续使用原始 NSIS `.exe`；不再支持旧式 `.exe.zip` / `.msi.zip` 更新包。

本轮审计的 vulnerability 条目从 17 项降为 0，仍保留 7 条上游停止维护提示与 1 条 Linux GTK/glib
健全性提示，没有加入公告忽略项。Linux 依赖链仍需后续处理，不表示所有平台均已无安全告警。

## 平台说明

- **Windows**：支持应用内检查更新；安装包未做 Authenticode 签名，SmartScreen 提示见安装说明。
- **macOS**：仅 Apple Silicon；应用未经 Developer ID 签名和公证，安装说明见下文。
  暂不支持应用内自动更新，请手动下载新 DMG。
- **Linux**：暂无安装包，凭据管理器及官方桌面端管理仍不可用。
- alpha 阶段数据格式与界面仍可能调整；同一数据目录不支持多个 PHL 窗口同时管理同一个实例。
