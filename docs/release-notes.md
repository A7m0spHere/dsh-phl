# PHL 0.1.0-rc.1

这是 PHL 0.1.0 的首个发布候选，面向 Windows x64。RC 阶段仍可能根据试用反馈修正问题。

## 本版更新

- **安全复制 DSH 会话。** PHL 会按可确认的会话格式处理复制；遇到当前不能安全保留的格式时明确拒绝，并保持目标目录不变，避免生成无法启动或内容不完整的副本。
- **检查已知插件冲突。** 对 PHL 管理的实例，可识别已验证会破坏 DSH WebUI 的 Browser Use / Chrome DevTools MCP 配置，并提供修复和复查。外部实例仍保持只读，不会被 PHL 擅自修改。
- **明确版本是否可安装。** 版本目录会区分上游可见信息与本地实际可安装的发布包；缺少安装包的版本不会显示为可直接安装。
- **整理实例与数据根状态管理。** 收拢实例生命周期、快照和数据根操作，降低切换根目录及多页面状态不同步的风险。

## 已知情况

- 本轮覆盖 Windows x64；不包含 macOS 支持。
- 真实 Windows 桌面验收覆盖 125% 缩放；100% 和 150% DPI 未纳入本轮矩阵。
- 会话复制经过官方 reader 和隔离 DSH 服务交叉验证；本轮未发送模型请求，也未验收真实模型续聊。
- 安装包尚未做 Authenticode 代码签名，首次下载和运行可能出现浏览器或 Windows SmartScreen 提示；请核对同一 Release 附带的 SHA-256 文件。
- PHL 自动更新需要已配置 updater 签名密钥；发布门禁要求 RC 附带 `.sig` 与 `latest.json` 更新清单。
