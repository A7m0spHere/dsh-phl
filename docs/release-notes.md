# PHL 0.1.0-alpha.5

这一版集中修正三处真机暴露的可靠性问题——保留端口导致 WebUI 打不开、卸载最后一个插件后实例启动即退、固定端口实例被自身登记误挡——并修复 tooltip 被卡片裁切；发布链路自此增加机器判定的发布前门禁。

## 可靠性与安全

- 实例端口不再落入浏览器保留端口：此前接入/整合包实例可能把 WebUI 开在 0/1 这类端口上，打开必然是 ERR_UNSAFE_PORT 错误页。现在新建实例从 3080 起建议；存量坏记录在「停止 → 启动」后自动换用可用端口并写回；关闭自动分配时选择保留端口会被直接拒绝启动并说明原因。
- 卸载实例的最后一个插件后，插件注册文件（cordis.patch.yml）保持合法的顶层数组；此前最后一个插件被卸载后实例会启动即退（must be a top-level YAML array）。已被此问题损坏的存量文件会在下一次插件写入时自愈。
- 固定端口实例启动不再被自身登记误报「端口正在被本实例使用」；端口确实被其他运行中实例占用时，报错指明占用者并给出解法。
- 发布流水线新增发布前机器判定：完整用户旅程的无头真实安装链测试（冷装 → 启动 → 重启接管 → 快照回滚 → 整合包新机重建 → 数据迁移 → 更新清单契约）、系统级故障注入（强杀、下载断流续传、取消续传绝不混拼异体内容、目标锁死、晚退出），以及安装器静默安装 → 首启核验 → 覆盖升级 → 卸载且用户数据保留的冒烟门禁。任一失败不发布。

## 使用体验

- 实例卡片与详情页的悬浮提示不再被卡片边缘裁成黑条；「上次退出」徽标完整显示退出码、运行时长与日志位置，「编辑」「查看详情」「更多操作」等提示悬停即可完整阅读。
- 贴近窗口右缘的提示气泡自动改为右对齐钉入视口，长文本换行显示，不再溢出屏幕外。

## 说明

- alpha.4 用户可以在「设置 → 关于」中直接检查并安装本版本；更早版本仍需先手动安装 alpha.3 或更高版本。
- 安装包仍未做 Authenticode 代码签名，首次下载与运行可能出现 SmartScreen 提示。
- alpha 阶段的数据格式与界面仍可能调整；同一数据目录不支持多个 PHL 窗口同时管理同一个实例。
