# 隐私声明 / Privacy

PHL 不收集、不上传任何用户数据。

- **没有遥测**：没有埋点、没有崩溃上报、没有账号体系，应用不向任何服务器回传使用数据。
- **网络请求只在用户主动操作时发生**：拉取 DSH 版本目录与插件信息（`api.github.com`、`registry.npmjs.org`），
  下载 DSH 与 Node 运行时（GitHub Releases；在 `gh-proxy.com` 镜像可用时会作为加速源一并尝试）。
  这些请求只携带常规的 HTTP 头，不包含你的实例内容或凭据。
- **数据都留在本机**：实例目录、PHL 数据目录与你在界面上指定的路径。
  API Key 存在**操作系统凭据管理器**，不写入任何配置文件；日志里的密钥按脱敏规则处理。
- **卸载**不会主动删除你的实例数据；是否保留由安装程序选项决定。

如果发现本声明与实际行为不符，请提 issue——这类问题优先处理。
